This document establishes the bidirectional mapping between all business capabilities and source code files.

| Feature Domain | Business Functionality | API Route(s) | Service Class | CRUD Class | SQLAlchemy Model | Pydantic v2 Schemas |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
